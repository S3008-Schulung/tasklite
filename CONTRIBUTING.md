# Mitmachen bei TaskLite

1. Repo **forken** (Button oben rechts) und Fork klonen.
2. Topic-Branch anlegen: `git switch -c fix/kurzbeschreibung`
3. Aendern, testen (`python3 -m unittest -q`), committen, pushen.
4. Im Fork **Contribute -> Open a pull request** (Base: dieses Repo, `main`).
5. Fork aktuell halten: Remote `upstream` einrichten und regelmaessig syncen.

Kleine Beitraege (Tippfehler, Doku) sind ausdruecklich willkommen —
siehe TODO.md.
